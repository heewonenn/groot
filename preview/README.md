# Приватный статический предпросмотр

Этот адаптер используется только в отдельной сборке для Sites. Он не подключает
браузер к реальным DEV/PROD, не вызывает модель и не заменяет FastAPI.
Обращения и решения сохраняются в `localStorage` данного браузера.

`build_data.py` вызывает явный синтетический `participant3_demo.seed()` в
временной SQLite и настоящий общий `services.scoring.calculate` участника №1.
Для каждой исходной версии из восьми критериев он предварительно рассчитывает
все 5184 разрешённые комбинации. JavaScript только выбирает готовый результат:
второй формулы баллов во frontend нет. При изменении правил нужно пересобрать
файл; новые правила статический адаптер не публикует.

Сборка данных из корня проекта:

```powershell
.\.venv\Scripts\python.exe preview\build_data.py
```

Только в отдельной копии frontend для Sites:

1. Скопировать `preview/public/*` в `frontend/public/`.
2. Перед React-рендером установить `axios.defaults.adapter = 'fetch'`, импортировать
   `/preview-fetch.js` и дождаться `globalThis.__CQA_PREVIEW_BOOT__`.
3. Показывать заметный баннер: «Синтетический предпросмотр. Сохранение только в
   этом браузере; модель не запускается. Полная версия работает с FastAPI».
4. Сброс вызывает `globalThis.__CQA_PREVIEW_RESET__()` и перезагружает страницу.
5. Стартовый вид: `?view=analysis&group_id=SYNTHETIC`. Навигация через `?view=`
   работает без серверного fallback для SPA.

Ссылки загрузки можно разместить рядом с баннером:

```html
<a href="/CQA-participant-3.zip" download>Скачать исходники</a>
<a href="/CQA-participant-3.patch" download>Скачать Git-патч</a>
<button type="button" id="preview-reset">Сбросить демо</button>
```

Не добавляйте реальные транскрипты, ссылки организаторов, подписанные аудиоссылки
или ключи в `preview-data.json`. Официальный экспорт намеренно отклоняет демо.
В рабочей локальной сборке Axios использует обычный API, адаптер не загружается.

Модуль участника №2 включён в полную сборку. В статическом предпросмотре
`GET /api/model-status` явно возвращает `configured=false`, `ready=false`
и `reason="static_preview"`; это ограничение сайта, а не отсутствие модуля.
История `GET /api/evaluation-runs?group_id=...&conversation_id=...` пуста.
Для искусственных карточек `runtime.model_run=null`: длительности попыток,
токены и стоимость не выдумываются. Точный запуск и его snapshot-доказательства
недоступны с HTTP 404, поскольку реального inference здесь не было.
Создание/повтор задания модели отклоняются с 503. Необходим запуск общего
FastAPI через `backend.app.model_app:create_configured_app --factory`
и согласованная серверная конфигурация поставщика.
