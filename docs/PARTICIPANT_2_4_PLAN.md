# План сдачи WE ARE GROOT · участники № 2 и № 4

Мы отвечаем за модель, доказательства, данные, аудио и выгрузку. Основной результат работы — два проверенных файла в ветке, которую откроет жюри. До выдачи контроля можно закончить все шаги, кроме обработки PROD.

## Что проверено

В первом проходе 8 ноября, до обновления квоты, у 30 из 65 диалогов DEV была завершённая оценка. Для всех 240 ответов проверены номера реплик и диапазоны доказательств, для каждого диалога независимо пересчитан итог. Из них 28 диалогов оценила Dots и 2 диалога оценила Gemini 3.8 Flash. По остальным 35 диалогам последние попытки обоих провайдеров завершились с HTTP 429. В выгрузке такие строки имеют статус `error` и `score: null`. Текущий результат хранится в [файле DEV](../results/dev/results.json).

Установка по README, сборка фронтенда и запуск учебной карточки проверены из чистого клона. Изменения команды находятся в ветке `codex/participant-2`. Ветка для жюри и идентификатор контрольной группы требуют подтверждения организаторов или капитана. [PR команды](https://github.com/heewonenn/groot/pull/6)

На 8 ноября в DEV загружено 65 диалогов и 1 268 реплик. Для первых чатов RU, KZ и EN сохранены оценки по восьми критериям. У всех трёх итог 92,31. Расчёт с исключением N/A проверен отдельно, ссылки из всех 24 ответов сверены с исходными репликами. Русский чат оценила Gemini 3.8 Flash за 98,7 секунды. В казахском и английском чатах после временного сбоя Gemini сработал резерв OpenRouter. С учётом переключения задания заняли 72,0 и 73,4 секунды соответственно.

В английском чате `p1-en-001` модель поставила максимум по критерию 04. В реплике `m0010` оператор объясняет, как продолжить регистрацию. Утверждение о сохранении логина после закрытия счёта требует сверки с официальным справочником. Перед защитой нужно либо найти подтверждение, либо передать этот вывод проверяющему.

Звонок `p4-ru-001` получил 92,50 по транскрипту. Первый запуск завершился по тайм-ауту обеих моделей. Повтор через OpenRouter занял 105,9 секунды. Ссылки по всем восьми критериям и итог с учётом N/A проверены. В плеере проверен переход к реплике `m0027` на 140,25 секунды. По критерию 06 модель сняла баллы за формулировки из фрагмента `m0026–m0043`. Обе процитированные фразы есть в транскрипте. Проверяющему стоит прослушать этот участок, чтобы отличить речь оператора от возможной ошибки расшифровки.

**Замена критерия проверена на DEV.** В редакторе изменили только инструкцию критерия 01 и опубликовали `freedom-chat@2`. На одном чате `p1-ru-014` одна и та же модель Dots сослалась на `m0010`. С требованием представиться ответ был «Нет» (итог 81,25), после публикации правила о приветствии ответ стал «Да» (93,75). На компьютере команды доступны [исходная карточка](http://127.0.0.1:5173/analysis?group_id=DEV&conversation_id=p1-ru-014&evaluation_id=d6e2b204-9790-4169-9522-bec5722038f5) и [новая карточка](http://127.0.0.1:5173/analysis?group_id=DEV&conversation_id=p1-ru-014&evaluation_id=54f2fea8-424f-49d8-8749-847a8c0c253e). Для сдачи используется исходная версия.

**Пересмотр.** На учебном английском чате через интерфейс оспорили критерий 04, сохранили решение с обоснованием и проверили результат после перезагрузки страницы. ## Первая реальная оценка

Команды выполняются в PowerShell 7 из корня репозитория после установки зависимостей. Для уже реализованного подключения Google выберите доступную вашему проекту модель Gemini с поддержкой структурированных ответов и совместимыми параметрами. Проверяйте доступность и квоты в своём кабинете. Сервер обращается к модели, когда создаётся задание. [Получить ключ в AI Studio](https://aistudio.google.com/apikey) · [Настройка Gemini](PARTICIPANT_2_HANDOFF.md) · [Квоты Google](https://ai.google.dev/gemini-api/docs/rate-limits)

```powershell
pwsh -STA -NoProfile -File scripts/start-google-pair.ps1 -KeyDialog
```

Скрипт запрашивает ключ скрытым вводом и проверяет каталог Google. На компьютере команды в `/api/model-status` основная модель указана как `gemini-3.8-flash`, резервная как `dots-studio/dots-3-note-preview:free` с провайдером `openrouter`. Резерв подключается отдельно командой ниже. Обе модели получают транскрипт. Запись в плеере проверяет человек.

Во втором терминале из корня запустите `cd frontend`, затем `npm run dev`. Откройте DEV, выберите диалог и версию правил и нажмите «Оценить диалог». Ключ вводится в локальном окне запуска сервера. [Открыть первый чат](http://127.0.0.1:5173/analysis?group_id=DEV&conversation_id=p1-ru-001)

**Резерв OpenRouter.** При ошибке квоты, сети или временном сбое Gemini резерв получает тот же транскрипт и чек-лист. На Windows команда `.\.venv\Scripts\python.exe -m backend.app.connect_openrouter` открывает вход и проверяет бесплатный маршрут на учебном диалоге. Сервер проверяет JSON по полной схеме, ссылки на реплики и правила чек-листа. Записи попыток сохраняют фактическую модель. Для ручной конфигурации остаются переменные `CQA_FALLBACK_PROVIDER`, `CQA_FALLBACK_MODEL`, `CQA_FALLBACK_CONTEXT_TOKENS` и `OPENROUTER_API_KEY`. [Инструкция по подключению](PARTICIPANT_2_HANDOFF.md#резерв-через-openrouter-на-windows)

## Команды на сдачу

Из корня, в отдельном терминале, при запущенном API. Если сервер использует `CQA_DB_PATH`, задайте тот же путь здесь. В штатном сценарии используется `data/cqa.sqlite3`. Команда `run dev` ниже предназначена для первого пакетного запуска. Для продолжения сохранённой обработки откройте последнее задание в цепочке, вызовите `POST /api/evaluation-jobs/{job_id}/retry` и экспортируйте по ID исходных заданий. Успешные диалоги сохраняют свои оценки. [Команды экспорта](../results/README.md)

```powershell
$python = '.\.venv\Scripts\python.exe'
$model = (Invoke-RestMethod http://127.0.0.1:8765/api/model-status).model
& $python -m backend.app.submission status dev
& $python -m backend.app.submission run dev --model $model --mode external_api --compact
& $python -m backend.app.submission check dev
```

Перед выдачей контроля сделайте push проверенного DEV. После выдачи задайте источник организаторов на сервере, получите группу и выполните команды.

```powershell
$group = Read-Host 'Выданный организаторами group_id'
$encoded = [Uri]::EscapeDataString($group)
Invoke-RestMethod -Method Post -Uri "http://127.0.0.1:8765/api/groups/$encoded/import"
& $python -m backend.app.submission run prod --group-id $group --model $model --mode external_api --compact
& $python -m backend.app.submission check prod --group-id $group
```

После успешной проверки добавьте соответствующий JSON в Git, сделайте коммит и push. Откройте файлы на GitHub именно в ветке, ссылку на которую получило жюри. Если передана ссылка на `main`, завершите слияние до стоп-кода. [Выгрузка, повторы ошибок и push](../results/README.md) · [Подключение источника](ZIP_INTEGRATION.md)
