## Проверяемое поведение

При пересмотре карточки сохраняются исходная оценка, комментарий, обоснование,
решение и доказательства. Итог пересчитывается общим модулем №1 по версии
чек-листа исходной оценки. Обновление страницы сохраняет историю.

В существующий браузерный сценарий добавлена явная проверка отображения после F5:

- перехода 15 → 20 и обоснования решения;
- текста исходного обращения после раскрытия истории;
- полной привязки `SYNTHETIC / synthetic-contract-001 / synthetic-contract-001:m0006`.

Проверка использует настоящий FastAPI, SQLite и Vite. Все диалоги в тестах
искусственные. 85,38 → 93,08 проверяет пересчёт; это не измерение качества AI.

Отдельный новый сценарий сохраняет обращение в учебной EN-карточке, ожидающей
официального источника. После закрытия окна, F5 и повторного открытия сохранены
тот же ID, комментарий, статус open и decision=null. Исходная и финальная оценки,
ответы, ревизия и история совпадают с состоянием до обращения. Запросов решения
не отправлено, кнопка применения без обоснования заблокирована, ошибок JavaScript
нет. Настоящая апелляция `p1-en-001` этим тестом не изменяется.

## Воспроизведение

На Windows при установленных зависимостях остановите свои dev-серверы и
запустите из корня:

```powershell
pwsh -NoProfile -File scripts/verify.ps1
```

Этот скрипт непосредственно здесь не запускался: PowerShell отсутствует.
Выполнены его эквивалентные проверки с установленными lockfile-зависимостями.
Личная Windows-машина и компьютер защиты этой проверкой не подтверждаются.

Для отдельной репетиции используйте [сценарий №3](PARTICIPANT_3_DEFENSE.md).
Он создаёт отдельный учебный файл базы и отключает внешнюю модель.

## Что остаётся отдельной работой

- Участник №1 согласовывает спорные трактовки предварительного разбора.
- Участник №2 сравнивает оценки с исходными запусками. Черновик ChatGPT
  не становится независимыми человеческими оценками автоматически.
- PR №11 содержит отчёт №2 о 65 DEV-диалогах и 520 ответах. Этот факт не
  заменяет измерение точности, проверку текущей квоты или повтор живой генерации.
- По английской апелляции нужен прямой официальный источник о логине после
  закрытия счёта. Общая база и статус этой апелляции в данной работе не менялись.
- №4 продолжает подготовку компьютера защиты, доступности реального аудио,
  резервной копии общей базы и контрольной сдачи. Desktop и 360px-снимки искусственных
  карточек просмотрены; они не доказывают синхронизацию настоящих звонков.
- Пятиминутная командная репетиция и контрольная сдача требуют отдельного
  выполнения. Учебный внутренний отчёт карточки не является `results.json`.

Приватные бланки, модельные ответы, базы, локальные конфигурации и снимки
не входят в изменения для GitHub.
