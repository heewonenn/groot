## Подтверждённое поведение части 3

- Переход к доказательству использует группу, диалог и исходный `message_id`.
  Сообщения с одинаковым временем остаются различными.
- Комментарий, решение, обоснование и доказательства сохраняются. После F5
  видны прежний комментарий, переход 15 → 20 и полная ссылка на реплику.
- Общий модуль №1 пересчитывает результат по исходной версии чек-листа.
  Оригинальный ответ и исходный итог сохраняются отдельно от пересмотра.
- Открытая апелляция после закрытия окна, F5 и повторного открытия сохраняет
  ID и комментарий. Без решения оценки, ответы, ревизия и история не меняются.
- Неразрешённый ответ остаётся частичным, с неизвестным исходным итогом.
  Ручное решение формирует отдельный финальный результат.
- N/A и отдельный флаг грубой ошибки работают через общий расчёт.
- Очередь оценщика передаёт карточке версию, причины, доказательства и сведения
  конкретного запуска. Ошибки и явный повтор сохраняются в истории.
- После смены версии правил прежние оценки и их правила остаются доступны.
- Ошибка загрузки восстанавливается повтором с клавиатуры; сценарий на 360 px
  не выходит за ширину экрана. Звонок без записи не получает выдуманный плеер.
- Неполный учебный набор не скачивается как фиктивная официальная сдача.

PR №14 сохраняет контракт ответов. Его неразрешённый продуктовый критерий,
временная область анализа и ссылки на источники поддержаны карточкой.
Техническая совместимость не является измерением точности нового промпта.
85,38 → 93,08 — искусственная проверка арифметики.

## Граница готовности

Материальных незакрытых требований к коду карточки, доказательств, апелляций
и истории не найдено. Технический модуль №3 готов на проверенной общей базе.

Личная разметка передаётся №2 отдельно; приватные ответы и подтверждения
проверяющих в GitHub не публикуются. Для содержательного завершения нужны
официальные источники по открытым продуктовым фактам и согласование спорных
трактовок. Для независимой оценки нужны новые примеры и человеческие ответы,
зафиксированные до просмотра прогнозов AI. Точность и полный Ground Truth
этой технической приёмкой не подтверждаются.

Настоящее аудио, доступная квота, живой ответ девятого критерия, контрольная группа
и компьютер защиты проверяются ответственными участниками отдельно.
В этой работе их результаты не подменяются синтетическими.

## Воспроизведение и передача

На Windows при установленных зависимостях остановите свои dev-серверы
и запустите из корня:

```powershell
pwsh -NoProfile -File scripts/verify.ps1
```

PowerShell в этой Linux-среде отсутствует: штатный скрипт непосредственно
не запускался, выполнены эквивалентные проверки. Новая установка на Windows
и запуск на компьютере защиты не заявляются.
