# Скачивание results.json по новому PDF

HTTP-слой участника 3 использует уже существующий экспорт и валидатор участника 4.
Он не запускает модель, не сохраняет файл в репозиторий и ничего не публикует.
Исходный внутренний контракт `cqa-team-v1` с `message_id` сохраняется.

1. Импортируйте полный набор в одну группу: DEV — 60 чатов и 5 звонков,
   PROD — 10 контрольных чатов. Искусственная демонстрационная группа не подходит.
2. Подключённый участником 2 оценщик должен действительно обработать весь набор
   с исходными версиями `freedom-chat@1` и `freedom-call@1`. Ошибки обработки
   сохраняются; их не следует удалять из набора.
3. `GET /api/evaluation-jobs?group_id=DEV` возвращает сохранённые задания.
   Для экспорта выбирайте исходные задания с `parent_job_id=null`: связанные
   повторные попытки экспортёр найдёт сам. Независимые задания не должны
   содержать одинаковые диалоги. Выбранные задания должны покрывать весь набор.
4. Отправьте `POST /api/submissions/prepare` с JSON:

   ```json
   {
     "group_id": "DEV",
     "split": "dev",
     "job_ids": ["<исходное задание чатов>", "<исходное задание звонков>"],
     "team_name": "WE ARE GROOT",
     "model_mode": "local"
   }
   ```

   `model_mode` должен описывать фактический запуск модели: `local`,
   `external_api` или `hybrid`. Его нельзя определять по `live/cache/demo`.
   Название команды совпадает с существующей CLI-настройкой проекта.
5. Сервер вернёт UTF-8 файл `results.json` только после полной проверки.
   Сохраните его локально как `results/dev/results.json` или
   `results/prod/results.json`. Инструкция PDF о push не отменяет текущий
   запрет пользователя отправлять изменения в GitHub.

Официальный файл содержит исходные ответы AI и `original_result`. Апелляции
не переписывают качество модели; финал проверяющего и история доступны
в отдельном внутреннем audit-отчёте карточки. Доказательства переводятся
в номера с 1 по всему исходному массиву, включая клиента, бота и систему;
диапазоны включают обе границы. Грубая ошибка остаётся отдельным флагом.

Демо и неподтверждённый кеш отклоняются. Неудачные или частичные реальные
попытки включаются как `status="error"`, `criteria=[]`, `score=null`.
Неполный исходный набор, незавершённые задания, неподходящие версии,
повторяющиеся идентификаторы или приватные данные в обосновании дают HTTP 422.
Неимпортированная группа или отсутствующее задание выбранной группы дают 404;
недоступное хранилище — 503. В ответах об ошибках нет исходных расшифровок,
подписанных аудиоссылок или ошибок провайдера.
